# 快捷指令换域名：两条路

原快捷指令里写死了 `wloc-spoofer.wloc.workers.dev`。改不了通常是因为作者在 iCloud 分享时关掉了"允许编辑"，或者 URL 藏在「文本」动作里被变量包着。

## 路线 A：不碰快捷指令，加一个迁移模块（1 分钟，推荐）

原理：在代理里把旧域名的请求 302 跳到新域名，快捷指令照旧用。

| 客户端 | 导入 |
|---|---|
| 小火箭 / Surge | `https://wloc.bybot.si/modules/wloc-migrate.sgmodule` |
| Quantumult X | `https://wloc.bybot.si/modules/wloc-migrate.conf` |
| Loon | `https://wloc.bybot.si/modules/wloc-migrate.lpx` |
| Stash | `https://wloc.bybot.si/modules/wloc-migrate.stoverride` |

模块内容就三行：

```
[URL Rewrite]
^https?:\/\/wloc-spoofer\.wloc\.workers\.dev\/(.*) https://wloc.bybot.si/$1 302

[MITM]
hostname = %APPEND% wloc-spoofer.wloc.workers.dev
```

启用后**和 Apple WLOC 模块同时开着**，其余什么都不用动。旧快捷指令、旧网页选点、任何还在用那个域名的脚本，全部自动落到 `wloc.bybot.si`。

验证：手机 Safari 打开

```
https://wloc-spoofer.wloc.workers.dev/api/parse?u=https://maps.apple.com/?ll=22.5431,114.0579&format=json
```

返回 `{"lat":...}` 而不是 404/报错，说明 302 生效了。

> 必须开 MITM 才能改写 https 请求——这条模块会把 `wloc-spoofer.wloc.workers.dev` 加进 MITM 列表，用的还是你已经信任的那张 CA，不用重装证书。

## 路线 B：自己新建两个快捷指令（不依赖 MITM）

### B1「wloc 设置位置」

1. 快捷指令 App → 右上 `+` → 命名 `wloc 设置位置`
2. 点底部 ⓘ（详细信息）→ 打开「在共享表单中显示」→ 接收类型勾选：**URL、文本、Safari 网页**
3. 依次添加动作：

| # | 动作 | 参数 |
|---|---|---|
| 1 | 获取快捷指令输入 | 类型：URL |
| 2 | URL 编码 | 输入：上一步结果 |
| 3 | 文本 | `https://wloc.bybot.si/api/parse?u=` ＋ 上一步变量 ＋ `&format=json` |
| 4 | 获取 URL 内容 | URL：上一步文本；方法 GET |
| 5 | 从输入获取词典值 | 键：`lat`；输入：第 4 步结果 |
| 6 | 从输入获取词典值 | 键：`lon`；输入：第 4 步结果 |
| 7 | 文本 | `https://gs-loc.apple.com/wloc-settings/save?lon=` ＋ 第 6 步变量 ＋ `&lat=` ＋ 第 5 步变量 |
| 8 | 获取 URL 内容 | URL：上一步文本；方法 GET |
| 9 | 显示通知 | `已设置 ` ＋ 第 5 步 ＋ `,` ＋ 第 6 步 |
| 10 | 打开 URL | `App-prefs:Privacy&path=LOCATION` |

第 10 步会跳到「设置 → 隐私与安全性 → 定位服务」，跟你原来的流程一致。

### B2「wloc 清理恢复位置」

三个动作就够：

| # | 动作 | 参数 |
|---|---|---|
| 1 | 获取 URL 内容 | `https://gs-loc.apple.com/wloc-settings/save?action=clear` |
| 2 | 显示通知 | `已清除虚拟定位，重启后恢复真实位置` |
| 3 | 打开 URL | `App-prefs:Privacy&path=LOCATION` |

### 用法

地图选点 → 分享 → 「wloc 设置位置」→ 跳转定位设置 → 重启手机。

## 怎么判断原快捷指令到底能不能改

快捷指令 App → 打开该指令 → 右上 `⋯`：

- 顶部出现「**无法编辑**」灰条 → 作者锁了，走路线 A 或 B
- 能进编辑 → 找「获取 URL 内容」动作，把 URL 里的 `wloc-spoofer.wloc.workers.dev` 换成 `wloc.bybot.si`（两处：设置和清理各一个）
